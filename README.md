# Business Analytics Portfolio

This repository contains selected work in Tableau, Python, and Jupyter Notebook. It includes operational analysis, public-service data, predictive modeling, traffic safety, and economic visualization.

## Featured projects

### Order Matching System Change Analysis

A Tableau evaluation of an order-allocation change. The analysis compares match-time distributions before and after implementation using the mean, median, percentiles, slow-match rates, and time-based diagnostics. Typical orders became slightly faster, while long waits became more common, so the change did not produce a clear overall improvement.

- [Project summary](ORDER_MATCHING_SYSTEM_CHANGE.md)
- [Full Tableau report](Order_Matching_System_Change_Analysis.pdf)

### NYC 311 Complaint Analysis

A Python analysis of 33.8 million NYC 311 records from 2010 through August 2023. It covers complaint categories, borough differences, seasonality, and long-term service-demand patterns. Saved tables and charts are included in the notebooks.

- [Detailed analysis](NYC_311_Complaint_Type_Distribution_Visualization.ipynb)
- [Focused complaint overview](complaint_type_visualization.ipynb)

### U.S. Economic Recovery After COVID-19

A Tableau course project on U.S. economic conditions during the pandemic and recovery. It brings together unemployment, interest rates, GDP, trade, fiscal balance, and state labor-market data in a visual narrative.

- [Project summary](US_ECONOMIC_RECOVERY.md)
- [Full presentation](US_Economic_Recovery_Visualization.pdf)
